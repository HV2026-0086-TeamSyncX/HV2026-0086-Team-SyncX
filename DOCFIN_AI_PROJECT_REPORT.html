01 Executive Summary & Project Mission

DocFin AI is a production-grade multimodal document intelligence platform designed to replace legacy OCR software and hallucination-prone generic chat interfaces. Built on Next.js 16, React 19, TypeScript 5, and powered by Google Gemini 2.0 Flash, DocFin transforms dense, static, multi-page PDF documents into actionable executive summaries, verified risk assessments, structured data tables, and interactive visual charts in sub-second intervals.

🎯 The Core Proposition: Zero Hallucination Guarantee
Modern corporate workflows in banking, law, healthcare, and academic research cannot tolerate AI hallucinations. DocFin enforces Spatial Coordinate Grounding: every insight, balance calculation, liability clause, and extracted number is strictly bounded to the exact page number and spatial coordinates of the original PDF source.

Key Architectural Highlights

  • Universal Multi-Domain Classification: Intelligently classifies uploaded documents into 6 distinct specialized lenses: Legal Contracts, Banking & Finance, Academic Research, Billing & Tax, Technical Specifications, and Insurance Policies.
  • Gemini 2.0 Flash Multimodal Pipeline: Ingests up to 50MB documents directly via native multimodal base64 buffers without text stripping or loss of visual table layouts.
  • Super-Action Intelligence Deck: Dynamic one-click routines tailored per document domain (e.g., overdraft penalty refund requests, early termination lease counter-clauses, WMT/BLEU benchmark extractions, and 50/30/20 budget optimizations).
  • Enterprise Ready Infrastructure: Complete Supabase PostgreSQL backend with Row-Level Security (RLS), optional Upstash Redis caching, Qdrant vector similarity indexing, and fully containerized Docker execution.

04 Gemini 2.0 Flash Reasoning & Grounding

The core multimodal processing pipeline in src/lib/geminiClient.ts leverages Google's flagship Gemini 2.0 Flash model. It features a multi-tiered resilience architecture:

🛡️ Resilient Generation Pipeline (Multi-Model Cascading Fallback)
If API rate limits, model maintenance, or transient network timeouts occur, the generation client automatically cascades across: gemini-2.0-flash $ ightarrow$ gemini-1.5-flash $ ightarrow$ gemini-2.5-flash $ ightarrow$ gemini-1.5-pro with an 8-second circuit-breaker timeout per model attempt.

Anti-Bytecode Sanitization & Linguistic Validation

Raw PDF streams often contain binary markers (endstream, xref, font descriptors, and compressed PostScript bytecode). Before any analysis or RAG synthesis is fed to the model or UI, the proprietary isValidLinguisticSentence() filter strips corrupt bytecode, preventing gibberish leaks and ensuring 100% human-readable output.

Table Matrix Extraction & RFC 4180 CSV Generation

Static PDF tables are notorious for losing columnar alignment in traditional OCR. DocFin's structural table extractor detects tabular rows and columns, maps header cells, and renders both a high-fidelity interactive HTML table view and a one-click CSV Export complying with RFC 4180 specifications.

06 Security, Data Isolation & Privacy

🔒 Enterprise Security Standards
High-stakes financial and legal documents require rigorous data protection. DocFin AI enforces strict multi-layered security controls across both transit and rest.
  • Row-Level Security (RLS): The Supabase PostgreSQL database isolates document audit records strictly to authenticated user IDs (auth.uid() = user_id). Multi-tenant cross-talk is physically impossible at the database engine level.
  • Bring Your Own Key (BYOK): Users can provide their own Google Gemini API key via the client settings modal. The key is stored in browser session memory and passed securely via encrypted headers, completely bypassing server credential stores.
  • Zero Document Rentention Mode: When operating in temporary audit mode, documents are parsed in transient RAM buffers and immediately garbage collected following analysis completion.
  • Container Isolation: Docker containers run under an unprivileged nextjs system account (UID 1001) with read-only root filesystems and explicit standalone build bundling.
  • Standard Security Headers: Preconfigured HSTS, Content Security Policy (CSP), X-Content-Type-Options: nosniff, and X-Frame-Options: SAMEORIGIN to prevent clickjacking and injection attacks.

DocFin provides a dedicated observability endpoint at /api/health. It outputs granular telemetry including Node process uptime, Resident Set Size (RSS), heap consumption, and ping latencies across Google Gemini, Supabase, Upstash Redis, and Qdrant Cloud.
